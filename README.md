# study-notes

这是一个面向深度学习系统与后端工程的个人技术知识库，主要记录 PyTorch、分布式训练、NPU 适配、大模型架构和 AI 编程相关的原理分析、源码阅读与工程复盘。

## 主要内容

- PyTorch 张量并行（TP）、流水线并行（PP）、上下文并行（CP）和 DTensor；
- DeepSeek-V4、DeepSeekMoE、混合注意力、MoE 路由与长上下文执行流程；
- NPU/Ascend 训练适配、算子接入、编译器、通信、精度和性能问题定位；
- Python、C++、JVM/Java 后端及 AI 协作编程所需的工程基础；
- 真实训练日志、故障分析、补丁说明和实现方案复盘。

## 阅读方式

建议先从 [`index.md`](index.md) 找到主题，再沿笔记中的 Obsidian 双链阅读相关概念、对比和源码记录。涉及具体版本的 API、硬件能力和模型结果时，应以笔记中的官方来源链接和目标环境实测为准。

这个仓库更关注“为什么这样设计、数据如何流动、问题如何定位以及方案如何验证”，而不只是 API 用法或代码片段。
