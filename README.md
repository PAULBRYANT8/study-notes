# study-notes

这是一个面向深度学习系统、AI Infra 与后端工程的个人技术知识库，记录学习笔记、原理分析、源码阅读和工程复盘。

内容围绕 PyTorch、分布式训练、NPU/Ascend 适配和大模型执行展开，关注模型为什么这样设计、数据怎样流动、问题如何定位，以及怎样验证正确性和性能。

## 主要内容

- **训练基础与数值**：张量形状、Attention、梯度累积、混合精度、量化和显存估算。
- **分布式并行**：DP、FSDP、ZeRO、TP、PP、CP、EP、DTensor，以及通信和张量布局之间的关系。
- **模型结构与执行**：DeepSeek-V4、DeepSeekMoE、混合注意力、MoE 路由、多路残差流与长上下文处理。
- **NPU 适配与性能**：TorchTitan-NPU、融合算子接入、编译器、通信、精度对齐、性能分析和故障复盘。
- **工程基础与学习路线**：Python、C++、Linux 调试、JVM/Java 后端、推理引擎及 AI 协作编程。

## 阅读方式

1. 从上方“快速入口”选择主题，基础概念优先看个人学习笔记和 `concepts/`，工程案例看 `work/`。
2. 需要系统学习时，结合项目学习路线或 AI Infra 能力地图，再沿链接查阅具体概念、源码和原始资料。
3. 可将仓库目录作为 Obsidian 仓库打开，使用笔记中的 `[[双链]]`、反向链接与公式预览。本 README 使用相对路径链接，便于直接在 GitHub 浏览。

涉及具体模型、分支、API 或硬件能力的结论，以笔记标注的来源、对应版本源码和目标环境实测为准。个人理解、方案设想和已验证结果应分开阅读。

## 内容维护与远端同步

- **先核查，再上传**：每次推送前检查 `个人学习笔记/` 中本次待上传的新增、修改和重命名文件，包括已提交但尚未推送的改动。先修正事实、公式、示例和链接问题，再提交推送；没有该目录的改动时，无需重复核查全目录。
- **保留来源与适用条件**：无法核实的内容标明原因和来源，不把存疑结论写成确定事实，也不把某个实现的特点当作通用规律。
- **保留原文和学习意图**：`raw/` 中已有原文不改写；整理个人学习笔记时保留用户的主题和表达意图。
- **私人目录仅本地保存**：`resume/` 已通过 `.gitignore` 排除，不参与版本跟踪和后续远端同步，不使用强制添加绕过忽略规则。

完整的目录、命名、链接、公式及同步规则见 [SCHEMA.md](SCHEMA.md)；Agent 协作入口见 [AGENTS.md](AGENTS.md) 和 [CLAUDE.md](CLAUDE.md)。
