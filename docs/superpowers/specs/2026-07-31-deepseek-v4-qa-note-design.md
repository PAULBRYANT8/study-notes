# DeepSeek-V4 原始问答笔记设计

## 目标

在 `work/deepseek-v4.md` 中建立一份可持续追加的 DeepSeek-V4 原始问答记录。读者可以从顶部问题索引点击完整的原始提问，并直接跳转到正文中对应的原问题句子。

## 收录范围

- 首次只收录本次关于 Router 和 routed score 的原始问答。
- 后续只追加用户在对话中提出的 DeepSeek-V4 相关原始问答。
- 不回填或复制 `work` 目录已有的专题笔记。
- 不修改现有复盘、接入介绍或其他知识库文件。

## 文档结构

正式文档使用以下固定结构：

1. 一级标题“DeepSeek-V4 原始问答记录”。
2. 顶部“问题索引”，按提问顺序列出 Q001、Q002 等编号和完整原问题。
3. 每个索引项使用 Obsidian 块链接，直接指向正文中的原问题句子。
4. 每条问答包含编号与简短主题、记录日期、原问题、详细回答和返回问题索引链接。

示意结构：

```markdown
# DeepSeek-V4 原始问答记录

## 问题索引

- [[#^q001-router|Q001：Router 为每个 token 选择若干专家，并产生 routed score。这其中的Router指的是什么，请详细说明一下]]

## Q001：Router 指的是什么

- 记录日期：2026-07-31

> **原问题：** Router 为每个 token 选择若干专家，并产生 routed score。这其中的Router指的是什么，请详细说明一下 ^q001-router

### 回答

详细回答正文。

[[#问题索引|返回问题索引]]
```

## 锚点规则

- 每条问题使用永久编号，已有问题不得重新编号。
- 块锚点格式为 `q<三位编号>-<英文主题>`，例如 `q001-router`。
- 索引文字逐字保留用户完整原话，不改写成摘要，也不主动校正其中的空格或标点。
- 正文标题可以简化，但索引始终跳转到带块锚点的原问题句子，而不是依赖标题文本。
- 新增问题前检查编号和块锚点是否重复。

## 首条回答内容

Q001 的回答沿用本次对话中的解释，并整理为适合长期复习的结构：

1. Router 的定义及其在 MoE 层中的位置。
2. token 隐藏状态、Router logits、routing score、Top-K 专家编号和 gate weight 的关系。
3. 从隐藏向量到专家输出加权合并的完整数据流与公式。
4. DeepSeekMoE/DeepSeek-V4 路径中共享专家与路由专家的差异。
5. Router 的训练方式、负载均衡作用以及路由塌缩问题。
6. Router 与 Attention 的区别及常见误解。

回答会明确区分论文中的通用 MoE 机制与具体 DeepSeek-V4 实现，避免把未经当前资料确认的专家数量或实现细节写成 DeepSeek-V4 的既定配置。

## 验收标准

- `work/deepseek-v4.md` 存在且为有效 Markdown。
- 问题索引包含用户的完整原始问题。
- 索引中的 `q001-router` 与正文中的块锚点完全一致。
- 正文包含本次 Router 问题的详细回答。
- 当前其他工作区修改保持不变。
- 文档中不存在未完成标记、空章节或重复锚点。
